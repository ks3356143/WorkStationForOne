# 冒烟覆盖面

改动 `scripts/smoke.cjs` 前先读这里，确认自己那块已有断言、不要重复造。

exec、激活 Provider 后的 app-server 审批卡与 MCP 工具审批卡，二者都走 `scripts/stub-codex.cjs`，不调用模型；Provider 测试连接用本机 mock 端点覆盖成功与失败，模型列表拉取覆盖 `/models` 返回与选择回填，Provider 卡显示推断的鉴权方式与实际请求端点；空态点头部 Codex 标签会新建 Codex 会话并选中（目标 Agent 没有会话时标签页不能是死按钮），删除唯一会话后回到空态；Agent 工作区通过 `WS_PICK_WORKSPACE` 跳过原生对话框，但仍走目录校验；多会话并发用慢速 stub 让两个 Claude 会话同时运行，断言后发会话先完成时慢会话仍在等待，随后各自独立收尾；并发审批故意让两个 stub 复用同一个 `request_id`，验证允许甲后乙的卡仍在、拒绝乙后各自收尾。舰队控制台冒烟从状态栏打开，断言多会话分组、运行/审批汇总、状态筛选、预设保存/删除、用量统计、本机会话只读扫描与导入落库，再打开会话；导入后断言线程出现历史正文、工具卡与顶部历史说明条、`origin='import'` 与 `tools_json` 落库，已导入行可「补历史」；本机扫描用
