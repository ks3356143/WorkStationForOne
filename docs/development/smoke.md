# 冒烟覆盖面

改动 `scripts/smoke.cjs` 前先读这里，确认自己那块已有断言、不要重复造。

- `npm run smoke` — 先构建，再跑 383 项 UI 交互冒烟。加载真实主进程与 preload，UI 操作直接写进临时 SQLite（`userData`、`sessionData`、数据库都隔离到 `%TEMP%`），并断言「preload 桥可用」与「操作已落库」；跨重启持久化仍由 `npm run verify` 覆盖。Codex 部分覆盖继承 CLI 的只读 exec、激活 Provider 后的 app-server 审批卡与 MCP 工具审批卡，二者都走 `scripts/stub-codex.cjs`，不调用模型；Provider 测试连接用本机 mock 端点覆盖成功与失败，模型列表拉取覆盖 `/models` 返回与选择回填，Provider 卡显示推断的鉴权方式与实际请求端点；Agent 工作区通过 `WS_PICK_WORKSPACE` 跳过原生对话框，但仍走目录校验；多会话并发用慢速 stub 让两个 Claude 会话同时运行，断言后发会话先完成时慢会话仍在等待，随后各自独立收尾；并发审批故意让两个 stub 复用同一个 `request_id`，验证允许甲后乙的卡仍在、拒绝乙后各自收尾。舰队控制台冒烟从状态栏打开，断言多会话分组、运行/审批汇总、状态筛选、预设保存/删除、用量统计、本机会话只读扫描与导入落库，再打开会话；导入后断言线程出现历史正文、工具卡与顶部历史说明条、`origin='import'` 与 `tools_json` 落库，已导入行可「补历史」；本机扫描用 `WS_SESSION_SCAN_ROOT` 指向临时 home，不得读取真实 `~/.claude` / `~/.codex`。能力中心冒烟用 `WS_CLAUDE_PLUGIN_CLI` 指向 `scripts/stub-plugin-cli.cjs`、`WS_PICK_SKILL` 指向临时技能目录，验证市场读取、安装、启用、本地 SKILL.md 导入/详情/移除、MCP 添加/信任/启用、工具级权限、Codex Provider 会话说明与环境自检；Codex app-server 跑完后读取临时 `codex-home/config.toml`，断言外部 `memory` 与本地桥都在、默认审批为 `prompt` 且不含 Provider 密钥值；工作区冒烟在临时 workspace 写 `smoke-note.txt`，从 Agent 顶栏打开文件树并预览；自定义 stdio Server 用 `scripts/stub-mcp-server.cjs` 验证连接测试与工具清单（echo / stub_status），再移除；HTTP Server 用冒烟内置的 Streamable HTTP 探针验证添加 / 信任 / 启用 / 测试、解密请求头透传、SSE 工具清单与临时 `--mcp-config` 的 `http-mcp=http`；最后断言 Claude 子进程实际收到应用私有 `--plugin-dir`、外部 MCP 与 `--strict-mcp-config`，以及外部 MCP 会话的 `--permission-prompt-tool mcp__workstationforone__approval_request`。审批规则冒烟覆盖敏感工具卡不出现「此工作区允许」、「本会话允许」后同轮自动放行、MCP 卡「此工作区允许」后不再弹卡、设置页显示并可撤销规则、撤销后恢复审批与审计留痕；到点提醒那条按分钟匹配，冒烟会检测是否跨过分钟边界并在跨界时重建重试；提醒中心还覆盖「今天不再」写入静音、重开仍隐藏、静音计数与恢复全部清空；会话分叉覆盖最新回复的 CLI 真分叉提示与源 resumeId / pendingFork 落库；周视图覆盖未排期键盘排到周一、任务卡 Alt+→ 移动一天与焦点跟随。关键状态断言用条件等待，不再靠固定 sleep；View Transition 被打断产生的 AbortError 属于预期，必须被吞掉。
